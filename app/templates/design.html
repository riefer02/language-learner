View tabs

Looked-up phrase

One compact row per saved phrase in My terms: the row plays from the round play button without opening, and the caret on the right opens it for the full player, register, and corrections. Native details, so the row still works without JavaScript.

Scene reply

Listening companion on a mission step, composed from .help-tip. Collapsed by default so it supplements retrieval instead of replacing it. On a scene step, opening it plays the line and the button replays it.

Content flag

Forms

Helper text explains the constraint.

Rules

  • Use semantic tokens, not raw hex values, for new components.
  • One h1 per page; page titles are h2.
  • Every control needs a visible label or a verified accessible name.
  • Tests run against the page, not a screenshot: labels, focus, mobile width.
  • Legacy rules migrate opportunistically; do not add new hard-coded colors.
